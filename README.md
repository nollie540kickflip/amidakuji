# 休日出勤あみだくじ

休日出勤の当番をあみだくじで決める、単一HTMLファイルのWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- メンバーは2〜10人まで、名前を編集できます
- 当番人数を設定でき、結果（休日出勤／お休み／午前のみ出勤など）は変更・シャッフルできます
- 名前をタップして1人ずつ、または「全員いっせいにたどる」でアニメーション付きで線をたどります
- 結果発表パネルで当番・お休みの一覧と全員の結果表を表示し、結果をテキストでコピーできます

## ファイル

- `index.html` — アプリ本体（HTML/CSS/JSを1ファイルに収録）
- `space.json` — Muse スペースとしてのメタ情報
- `icon.webp` — アイコン
